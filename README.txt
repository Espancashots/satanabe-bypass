3105 Admin Panel

1. Hospede estes arquivos em qualquer host estático HTTPS (GitHub Pages, Netlify, Vercel etc.).
2. Crie/entre em uma conta no painel.
3. Na primeira conta administrativa, informe o código de bootstrap fornecido separadamente.
4. Depois do bootstrap, o código deixa de aceitar novos administradores automaticamente.

O painel usa somente a publishable key no navegador. Chaves privilegiadas ficam apenas nas Edge Functions do Supabase.
